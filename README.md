# КТ 2 — Корзина

Используйте английский интерфейс и начинайте каждый сценарий в новом контексте Playwright. Работайте с магазином через браузер. Используйте локаторы Playwright и утверждения с автоматическим ожиданием.

## Задания

1. **`addProduct(name)`**. Открыть товар из каталога по названию и нажать `Add to cart` на странице товара. В тесте открыть корзину и увидеть добавленный товар.
2. **`open()`**. Открыть корзину через ссылку `Cart` в шапке. В тесте проверить путь `/cart` и наличие действия `Continue shopping`. Каждый тест начинает работу с пустой корзиной.
3. **`removeProduct(name)`**. На странице корзины нажать `Delete` внутри строки указанного товара. Добавить два разных товара и убедиться, что после удаления второй товар остался.
4. **`clear()`**. Очистить заполненную корзину кнопкой `Clear cart`. В тесте добавить два товара и проверить, что обе строки исчезли.

## Структура проекта

- `pages/CartPage.js` — реализуйте четыре асинхронных метода класса `CartPage`. Сохраните именованный экспорт, имена методов и аргументы.
- `tests/02-cart.spec.js` — напишите четыре теста, по одному на задание. Названия тестов начинаются с `[1]`, `[2]`, `[3]`, `[4]` соответственно. Вызовите соответствующий метод Page Object и проверьте результат через `expect`.
- `playwright.config.js` — конфигурация Chromium и адрес магазина.

Стартовый набросок каждого теста содержит вызов метода. Допишите подготовку данных и проверки по условию. Закрытая проверка вызывает методы с другими данными и проверяет результат в браузере. Темы этой работы — локаторы, действия и события, утверждения, Page Object Model и структура тестов. Для корзины нужна изоляция состояния между сценариями.


## Запуск и сдача

Сделайте форк этого репозитория, клонируйте форк и создайте рабочую ветку. В Page Object и тестах пишите код между маркерами `// BEGIN` и `// END`. В блоке каждого теста добавьте подготовку данных, вызов метода и утверждения по условию.

Используйте Node.js 22. В корне проекта выполните:

```sh
npm ci
npx playwright install chromium
npm test
```

После выполнения четырёх заданий откройте pull request из ветки своего форка в `main` исходного репозитория. Ссылку на PR сдайте в Moodle.
